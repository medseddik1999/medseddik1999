## 🧠 About Me

I'm a French Data Scientist interested in the intersection of **data science, financial systems, algorithms, and enterprise computing**.

- 📊 **Data Science:** Statistical analysis, machine learning, and predictive modeling.
- 💹 **Financial Engineering:** Cryptocurrency analytics and wallet optimization.
- 🕸️ **Network Science:** Graph analysis, complex systems, and relationships between entities.
- ⚙️ **Data Engineering:** Data transformation, processing, and analytical pipelines.
- 🏦 **Mainframe Computing:** COBOL and IBM z/OS.
- 🚀 **Builder mindset:** Developing projects that turn technical ideas into practical solutions.

> *From financial data and complex networks to enterprise-scale computing.*
